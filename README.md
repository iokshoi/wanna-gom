# 1. 앱 이름과 한 줄 소개

**워나곰**은 오늘 얼마나 집에 가고 싶은지 문장으로 적으면 점수와 작은 추천을 보여 주는 웹앱입니다.

## 2. 누구를 위한 앱인가

집에 가고 싶은 마음을 가볍게 표현하고 싶은 10~20대 학생을 위한 앱입니다.

## 3. 할 수 있는 일

- 한국어로 지금 기분을 적거나 예시 문장을 고를 수 있습니다.
- 버튼이나 Enter를 누르면 계산 중 화면을 거쳐 점수, 이유, 오늘의 추천을 볼 수 있습니다. Shift+Enter는 줄바꿈입니다.
- 기본 점수는 0~100점으로 계산하고, 화면에는 최대 1,000,000점으로 표시합니다.
- 입력이 비었거나 기본 규칙으로 판단할 수 없으면 안내 문구가 나옵니다.
- `다시 해보기`를 눌러 새 문장을 입력할 수 있습니다.

## 4. 사용 방법

1. `나의 오늘은...` 칸에 가상의 기분을 적습니다.
2. `집 가고 싶은 정도 보기`를 누르거나 Enter를 누릅니다.
3. 점수와 오늘의 추천을 확인합니다.
4. 다른 문장도 시험하려면 `다시 해보기`를 누릅니다.

일정 추가·완료 표시·삭제는 워나곰의 기능이 아닙니다.

## 5. 실행 방법

루트의 `index.html`을 브라우저로 직접 여세요. 이 방법은 설치 없이 기본 점수를 사용할 수 있습니다. AI 연결은 로컬 서버와 해당 서비스 로그인이 필요합니다.

## 6. 확인 방법

[회귀 점검표](docs/checklist.md)를 따라 확인하세요. 입력, 계산 중 화면, 점수와 추천, 다시 하기, 빈 입력 안내, Enter 동작이 핵심입니다. 결과 칸은 확인한 사람이 채웁니다.

## 7. 데이터 저장 안내

브라우저 localStorage에는 선택한 AI 종류만 저장됩니다. 다른 브라우저나 다른 주소에서는 이 선택이 보이지 않습니다. 기분 문장과 점수는 저장하지 않으므로 새로고침하면 사라집니다. 가상의 내용만 입력하세요. AI를 연결하면 입력 문장이 선택한 AI 서비스로 전송됩니다.

## 8. 만든 과정

- **프롬프트 엔지니어링:** [프롬프트 설계서](docs/prompt-design.md)에 목표와 점수 판단 방식을 적었습니다.
- **하네스 엔지니어링:** `AGENTS.md`에 실행 방법과 확인 규칙을 적고, 점검표로 결과를 기록하게 했습니다.
- **루프 엔지니어링:** [반복 기록](docs/loop-log.md)에 실패 기준, 수정 내용, 재검증 상태를 남겼습니다.
