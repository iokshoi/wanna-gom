# ★ 워나곰 · 오늘의 집 가고 싶은 지수

> 수업, 과제, 사람들 사이에서 **집 생각이 난다면** — 지금 기분을 워나곰에게 말해줘! 🐻

지금 기분을 한 줄 적으면 워나곰이 **집에 가고 싶은 정도를 최대 1,000,000점**으로 알려 주고, 기분에 맞는 **오늘의 추천**도 하나 골라 줍니다.

![워나곰 메인 화면](docs/images/main-screen.png)

## ✦ 이런 걸 해요

| | |
|---|---|
| ✍️ **한 줄 입력** | 최대 180자로 지금 기분을 적어요. 예시 버튼을 눌러 바로 시작할 수도 있어요. |
| 🔮 **계산 중 연출** | 별이 통통 튀는 로딩 화면을 보여 준 뒤 결과가 나와요. |
| 💯 **백만 점 점수** | 0~100점을 1,000,000점 단위로 환산해 숫자가 차오르는 애니메이션으로 보여 줘요. |
| 🌶️ **오늘의 추천** | 점수와 문장 속 맥락에 맞춰 엽떡, 간식, 노래 한 곡, 휴식 같은 추천을 골라 줘요. |
| 🤖 **AI 문맥 보정** | ChatGPT 또는 Claude를 골라 부정·반어·과장 표현까지 읽어 점수를 보정해요. |
| 🛟 **안전한 기본값** | AI가 없거나 실패해도 사전 규칙으로 점수와 추천을 항상 보여 줘요. |

## ✦ 점수는 이렇게 나와요

1. **사전 점수**: `집 가고 싶어`, `피곤`, `과제`, `당장` 같은 표현을 찾아 더하고, `괜찮아`나 부정 표현은 빼서 0~100점의 기본 점수를 만들어요.
2. **AI 보정 (선택)**: 고른 AI가 문장 전체의 뜻을 읽고 기본 점수를 참고해 최종 점수와 이유(피로·학업·사람·부정·반어·강조·기타)를 정해요.
3. **화면 점수**: 최종 점수 × 10,000 = 화면에 보이는 점수예요.

판단 근거가 부족한 문장에는 아무 점수나 주지 않고, 조금 더 구체적으로 적어 달라고 안내해요.

## ✦ 바로 실행하기

### 1. 기본 점수만 써 보기 (설치 없음)

`index.html`을 브라우저로 열면 끝이에요.

```bash
open index.html
```

### 2. AI 보정까지 써 보기 (로컬 서버)

[Node.js](https://nodejs.org/) 18 이상이 필요해요. 설치할 패키지는 없어요.

```bash
npm start
```

서버가 켜지면 👉 **http://127.0.0.1:4173** 에 접속하세요. 화면 아래 `AI 문맥 보정`에서 사용할 AI를 고를 수 있어요.

- **ChatGPT**: `Continue with ChatGPT`를 눌러 로그인하면 ChatGPT 플랜으로 보정해요.
- **Claude**: 이 컴퓨터의 [Claude Code](https://claude.com/claude-code)에 로그인되어 있으면 **내 Claude 플랜**으로 보정해요. API 키는 필요 없어요.
  - 계산할 때마다 플랜 사용량이 조금씩 차감되고, 몇 초 정도 더 걸려요.
  - 내 로그인으로 동작하니 나 혼자 로컬에서만 쓰세요.

## ✦ 폴더 구조

```
wanna-go-home/
├── index.html          # 화면 진입점
├── src/
│   ├── app.js          # 점수 계산, 화면 전환, AI 선택
│   └── styles.css      # 2yk + 팝 스타일 디자인
├── server.js           # 선택형 로컬 AI 서버 (ChatGPT 로그인 / Claude Code)
└── docs/               # 기획서, 프롬프트 설계, 점검 기록, 화면 캡처
```

## ✦ 보안 메모

- Claude는 Claude Code의 로그인을 그대로 써요. 서버는 Claude Code를 도구 없이(파일 읽기·명령 실행 없이) 답만 받도록 실행해요.
- ChatGPT 로그인 정보는 브라우저가 아니라 로컬 앱 저장소(`~/Library/Application Support/Wannagom`)에 보관돼요.
- 로컬 서버는 `127.0.0.1`에서만 열리고, 다른 주소에서 온 요청은 막아요.
