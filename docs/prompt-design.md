# 프롬프트 설계서

## 1. 목표
- 집에가고싶은 느낌을 말하면 점수로 치환해주는 앱을 만드는게 목표입니다.
- 디자인은 2yk + pop한 스타일로 구성해주세요
- 웹앱형태로 작성해주시면 됩니다.

## 2. 맥락
- 사용자가 집에가고싶은 느낌을 한국어로 텍스트로 입력합니다
- 사전 없이 AI가 한국어 문장 전체의 뜻을 해석해 집에 가고 싶은 강도를 0~100으로 판단하고, 이를 0~백만 점으로 환산합니다.
- 부정·반어·과장·비속어는 문맥에 따라 판단하며, 사용자에게 보여주는 설명에는 욕설을 사용하지 않습니다.
- 로컬 웹앱에서 ChatGPT 로그인과 사용자 동의를 통해 적격한 AI 요청에 현재 플랜을 사용합니다.
- 점수로 치환해주며, 오늘 하면 좋은 일을 추천해줍니다. ex) 엽떡먹기

## 3. 제약
- 사용자에게 욕설을 사용하지 않습니다.

## 4. 출력 형식
- 만들때 필요한 주요 기술과 그 이유를 알려주세요
- 화면에 보일 요소와 디자인의 느낌이나 참고할 것을 리스트업 해주세요
- 완료 기준을 어떤 순서로 어떻게 구현할지 알려주세요.

## 5. 완료 기준
- 실행 가능한 웹앱도 결과물에 포함
- 집가고싶은 느낌 적는 인풋창
- 계산하는 동안 보일 사용자 UX
- 계산된 값과 오늘의 추천
> 플로우 : 브라우저에서 한국어 문장을 입력해 계산 버튼을 누르면 계산 중 화면을 거쳐 0~백만점과 오늘의 추천이 표시된다
