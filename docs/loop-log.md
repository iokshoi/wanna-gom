# 반복 기록

## 1일차

- 시작 조건: `index.html`, `src/styles.css`, `src/app.js`가 브라우저에서 열린다.
- 완료 기준: ① Enter로 제출되고 Shift+Enter로 줄바꿈된다. ② AI 연결 시 사전 단어가 없는 문장도 점수와 추천이 나온다. ③ 콘솔 오류가 없다.
- 종료 조건: 사람이 완료 기준을 모두 확인하거나, 같은 실패 기준을 3회 고치면 멈춘다.

| 회차 | 실패한 기준 | 실패 근거(한 일 → 보인 것) | 보낸 피드백 요약 | 바뀐 파일 | 재검증 결과 |
|---|---|---|---|---|---|
| 처음 점검 | ① Enter 제출, ② AI 자유 입력 | 코드 확인: Enter 처리 없음 → 줄바꿈 / 사전 미일치 → 제출 차단 | Enter 제출과 AI 자유 입력 요청 | - | 수정 전 |
| 1회 | ①, ② | 위 두 경로 수정 | Enter 제출·AI 요청 범위 확장 | `index.html`, `src/app.js`, `server.js` | 자동 점검 통과, 브라우저 확인 대기 |

| 3회 | | | | | |

- 종료 이유: 브라우저 확인 대기
- 남은 문제: 실제 AI 응답과 브라우저 콘솔은 사람이 확인해야 한다.
- 다음에 지시를 바꾼다면: 실패한 문장과 화면 결과를 함께 적는다.
