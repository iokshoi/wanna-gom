# 앱 기획서

## 1. 앱 이름
- 워나곰

## 2. 사용자 (누가 쓰나)
- 일반적인 학생 10~20대 대상 

## 3. 해결할 문제 (왜 필요한가)
- 집에가고싶다를 계속 말하기 때문에 

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)
[필수]
- 자신이 집에가고싶은 문장 작성
- 사전과 가감점 규칙으로 0~100점의 기본 점수를 계산하고, AI가 문맥을 해석해 점수를 보완
- AI가 연결되지 않거나 계산에 실패하면 사전 규칙으로 계산한 결과를 제공
- 점수 + 오늘의 추천 요소를 사용자에게 출력

## 5. 화면 구성 (위에서 아래 순서)
- 입력 화면: 큰 제목, “지금 얼마나 집에 가고 싶어?” 안내, 한국어 문장 입력창, 예시 문장 버튼, `집가고싶은 정도 보기` 버튼.
- 계산 중 화면: 버튼을 잠시 비활성화하고 별·하트·게이지가 움직이는 짧은 전환 효과와 “기분 읽는 중…” 문구를 보여줍니다.
- 결과 화면: 0~100점의 계산 결과를 0~백만 점으로 환산해 숫자가 올라가는 연출과 함께 크게 표시하고, 단계별 별칭, 점수가 나온 이유 한 줄, “오늘의 추천” 카드, `다시 해보기` 버튼을 보여줍니다.
- 디자인: 크림색 바탕에 핫핑크·라임·하늘색 포인트, 굵고 둥근 글자, 크롬 느낌의 테두리와 스티커 장식. 작은 화면에서도 입력창과 결과가 먼저 읽히도록 구성합니다.
- 점수 규칙: “집 가고 싶다” 같은 직접 표현을 기준으로 피로·시험·과제·사람에 지침·강조 표현을 가산하고, “괜찮다”나 부정 표현은 감산해 기본 점수를 0~100으로 제한합니다. AI가 문맥을 보완한 최종 점수도 0~100으로 제한하고, 화면용 백만 점수는 최종 점수에 10,000을 곱합니다. 매칭 근거가 부족하면 임의의 점수 대신 문장을 더 구체적으로 적어 달라고 안내합니다.
- 추천 규칙: 점수 구간과 문장 속 맥락에 따라 간식, 엽떡 같은 식사, 산책, 휴식 중 한 가지를 고릅니다. 앱이 사용자에게 보여주는 문구에는 욕설을 넣지 않습니다.

## 6. 사용 흐름 (사용자가 하는 행동 순서)
- 집가고싶은 느낌 입력
- 점수 확인 버튼 클릭
- 점수 확인
- 다시하기 or 끝내기

## 7. 만들지 않을 것
- 요청사항 이외

## 8. 완료 기준
- - 실행 가능한 웹앱도 결과물에 포함
- 집가고싶은 느낌 적는 인풋창
- 계산하는 동안 보일 사용자 UX
- 계산된 값과 오늘의 추천
