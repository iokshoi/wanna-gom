## 회귀 점검표

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
|---|---|---|---|---|
| 0 | 콘솔 오류 없음 | 브라우저에서 루트의 `index.html`을 열고 개발자 도구 콘솔을 비운 뒤 새로고침한다. 아래 점검이 끝날 때까지 콘솔을 열어 둔다. | 새로고침과 점검 중 빨간 오류가 나타나지 않는다. | |
| ① | 기분 입력 | `나의 오늘은...` 입력칸에 `집에 가고 싶어`를 입력한다. | 입력한 문장이 보이고 글자 수가 `0 / 180`에서 바뀐다. | |
| ② | 계산 중 화면 | AI 연결 없이 ①의 문장을 입력한 상태에서 `집 가고 싶은 정도 보기`를 한 번 누른다. | 결과가 나오기 전에 `기분 읽는 중...` 화면이 나타난다. | |
| ③ | 점수와 오늘의 추천 | ②의 계산이 끝날 때까지 기다린다. | `450,000 / 1,000,000`이 표시되고, 점수 이유와 `오늘의 추천` 카드가 보인다. | |
| ④ | 다시 해보기 | ③의 결과 화면에서 `다시 해보기`를 누른다. | 입력 화면으로 돌아오고 입력칸이 비어 있어 새 문장을 적을 수 있다. | |
| ④-1 | 빈 입력 | 비어 있는 입력칸에서 `집 가고 싶은 정도 보기`를 누른다. | 점수 화면으로 넘어가지 않고 `지금 기분을 한 줄 적어줘!` 안내가 보인다. | |
| ④-2 | 공백만 입력 | 입력칸에 스페이스 세 칸만 넣고 `집 가고 싶은 정도 보기`를 누른다. | 점수 화면으로 넘어가지 않고 빈 입력 안내가 보인다. | |
| ④-3 | 판단 근거 부족 | AI에 연결하지 않은 상태에서 입력칸에 `안녕`을 적고 `집 가고 싶은 정도 보기`를 누른다. | 임의의 점수를 표시하지 않고 기분을 더 구체적으로 적어 달라는 안내가 보인다. | |
| ⑤-1 | Enter와 줄바꿈 | 입력칸의 기존 문장을 지우고 `집에 가고 싶어`를 입력한다. `Shift+Enter`를 누른 뒤 다음 줄에 `피곤해`를 적고 `Enter`를 누른다. | `Shift+Enter`는 줄바꿈만 하고, `Enter`는 계산을 시작해 결과 화면으로 이동한다. | |
| ⑤-2 | AI 미연결 기본 점수 | `다시 해보기`를 누른 뒤 AI에 연결하지 않은 상태에서 `집에 가고 싶어`를 입력해 결과를 확인한다. | 점수와 추천이 표시되고, 사전 규칙으로 계산한 점수라는 안내가 보인다. | |
| ⑤-3 | AI 연결 문맥 보정 | 로컬 서버를 실행해 `http://127.0.0.1:4173`을 열고 ChatGPT 로그인 또는 Claude Code 연결을 마친다. 화면에서 연결된 AI를 선택하고 `오늘 하루가 길게 느껴져`를 입력해 결과를 확인한다. | 연결 상태가 보이고, AI가 0~100점으로 판단한 결과가 0~1,000,000점 화면 점수와 이유·추천으로 표시된다. 실제 계정 연결과 응답을 확인한 뒤에만 통과로 기록한다. | |
